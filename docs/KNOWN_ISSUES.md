# 알려진 문제 (0.1.0 RC1, 2026-10-26)

| # | 영역 | 내용 | 영향 | 우회·계획 |
|---|---|---|---|---|
| 1 | 설치 | 설치기(M6)가 없다. 라이브 ISO 는 홈이 휘발성이라 설정이 재부팅 후 사라진다. | 높음 | ARM64 qcow2 번들은 설정이 남는다. 설치기는 다음 마일스톤 |
| 2 | 소리 | 이미지에 PipeWire/wireplumber 가 없어 소리 표시기·설정이 숨겨진다 (설정 → 소리에 이유 표시). | 중간 | `packages.desktop` 에 pipewire pipewire-pulse wireplumber 추가 후 재빌드 (실기기 검증 필요) |
| 3 | 네트워크 | NetworkManager 가 설치되지 않은 이미지에서는 Wi-Fi 검색·연결을 제공하지 않고 인터페이스 상태만 보여 준다. | 중간 | `network-manager` 설치 시 nmcli 경로가 활성화된다 (파서는 단위 테스트 완료, 실기기 미검증) |
| 4 | 한글 입력 | fcitx5 통합(패키지·환경 변수·자동 시작)은 추가했으나 이 세션에서는 이미지를 재빌드하지 못해 실제 조합을 검증하지 못했다. | 중간 | 이미지 재빌드 후 수동 검사 (RELEASE_CHECKLIST §4) |
| 5 | 전원 | 유휴 시 화면 끄기·자동 절전 설정이 없다 (swayidle 미포함). 덮개·전원 단추 동작은 logind 기본. | 중간 | swayidle 포함 + 설정 UI 는 후속 |
| 6 | 시스템 트레이 | StatusNotifierItem(SNI) 호스트가 없어 외부 앱의 트레이 아이콘은 표시되지 않는다. 내장 표시기(네트워크·소리·배터리·알림)만 있다. | 중간 | M2 잔여 과제 |
| 7 | 작업 공간 | 4개 작업 공간과 단축키는 있으나 패널에 현재 작업 공간 표시기가 없다 (labwc 0.7 에 작업 공간 프로토콜 없음). | 낮음 | ext-workspace 프로토콜을 지원하는 labwc 버전에서 추가 |
| 8 | 창 장식 | labwc 서버 장식은 토큰의 색·여백만 받는다. 연화 제목 띠는 하그라 앱 내부에만 있고 외부 앱 창에는 없다. | 낮음 | 설계상 한계 (UI_FOUNDATION §2.2) |
| 9 | 번역 | 테마 팩 자산·외부 앱은 번역 범위 밖. 설정 백엔드 진단 문구 중 일부는 영어로만 나온다(명령 이름 등). | 낮음 | — |
| 10 | 화면 읽기 | HagraUI 에 접근성 역할·이름을 붙였지만 이미지에 AT-SPI 화면 읽기 프로그램이 없고 Qt Wayland 접근성 브리지는 검증하지 않았다. | 중간 | orca + at-spi2-core 포함 후 검증 |
| 11 | 키보드 배치 | 설정에서 바꾼 XKB 배치는 labwc 가 환경 파일을 다시 읽어야 적용된다. 재구성(Super+Shift+R)으로 반영되지 않으면 다음 로그인부터. | 낮음 | labwc 0.8 의 `<keyboard><layout>` 로 전환 예정 |
| 12 | 표시기 | 소리·배터리·네트워크 상태는 5초 폴링이다 (D-Bus 이벤트 아님). 변화가 최대 5초 늦게 보일 수 있다. | 낮음 | UPower/NM D-Bus 신호 구독으로 전환 가능 |
| 13 | 다중 모니터 | 출력마다 패널이 뜨고 팝업은 누른 패널의 출력에 나타난다. 헤드리스 2출력으로만 검증했고 실제 두 모니터·서로 다른 배율은 미검증. | 중간 | 실기기 체크리스트 |
| 14 | 알림 | 알림 소리·아이콘 이미지(hints image-data)는 표시하지 않는다. 동작 버튼·긴급·방해 금지·센터는 동작한다. | 낮음 | — |
| 15 | 종료 로그 | 셸 종료 시 `[destroyed object] surface was destroyed before its role object` 가 드물게 기록된다 (기능 영향 없음; 종료 순서 수정 적용). | 낮음 | 헤드리스 테스트에서 재발 여부 감시 |
