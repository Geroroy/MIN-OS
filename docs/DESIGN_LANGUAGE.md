# MIN 디자인 언어

> "Minimal. Independent. Native." — 기능이 형태를 결정한다. 장식은 정보가 아니면 넣지 않는다.

Windows 2000/XP의 **기능적** 설계(명확한 경계, 높은 밀도, 예측 가능한 배치, 키보드 접근)를 참고하되,
그 외형(입체 베벨, 그라디언트, 둥근 버튼)은 복제하지 않는다. MIN의 형태는 평면·직각·1px 선이다.

## 1. 기본 원칙

1. **각진 형태** — 모든 창, 버튼, 입력란, 메뉴의 모서리 반경은 0px.
2. **얇고 명확한 테두리** — 1px 단색 테두리. 그림자 없음. 계층은 테두리 명도 차이로 표현한다.
3. **무채색 중심** — UI는 회색 단계로 구성. 색은 상태(포커스·선택·경고)에만 사용하고, 한 화면에 강조색은 한 종류만 쓴다.
4. **높은 정보 밀도** — 기본 글꼴 12px, 행 높이 20px, 패딩 4/8px. 여백은 그룹을 나눌 때만 넓힌다.
5. **애니메이션 최소화** — 상태 변화는 즉시 반영. 허용되는 애니메이션은 진행 표시기와 커서 점멸만이다.
6. **일관성** — 모든 MIN 앱은 MinUI 컨트롤만 사용한다. 같은 동작은 같은 위치·같은 단축키로.
7. **키보드 우선** — 모든 기능은 키보드로 도달 가능하고, 포커스 표시는 항상 보인다.
8. **낮은 자원 사용** — 블러·투명·그림자 효과 없음. 소프트웨어 렌더러에서도 동일하게 보여야 한다.

## 2. 그리드와 치수

| 토큰 | 값 | 용도 |
|---|---|---|
| `unit` | 4px | 기본 간격 단위. 모든 치수는 unit의 배수 |
| `panelHeight` | 28px | 작업 표시줄 높이 |
| `titleBarHeight` | 22px | 창 제목 표시줄 (labwc 테마와 일치) |
| `rowHeight` | 20px | 목록·메뉴 행 |
| `controlHeight` | 22px | 버튼·입력란 |
| `borderWidth` | 1px | 모든 테두리 |
| `padding` | 4px / 8px | 컨트롤 내부 / 그룹 간 |
| `radius` | 0px | 고정 |
| `iconSize` | 16px / 24px | 목록·메뉴 / 실행기 |

## 3. 색상 토큰 — 기본 테마 "Graphite" (어두움)

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg` | `#1a1a1a` | 데스크톱 배경, 창 바탕 |
| `surface` | `#242424` | 패널, 메뉴, 입력란 바탕 |
| `surfaceRaised` | `#2e2e2e` | 호버된 행, 활성 버튼 |
| `border` | `#3a3a3a` | 기본 테두리 |
| `borderStrong` | `#5c5c5c` | 포커스 가능한 컨트롤 테두리, 활성 창 테두리 |
| `text` | `#e4e4e4` | 기본 텍스트 |
| `textMuted` | `#9a9a9a` | 보조 텍스트, 비활성 |
| `textDisabled` | `#5c5c5c` | 비활성 컨트롤 텍스트 |
| `accent` | `#3d7bd9` | 포커스 링, 선택 배경, 활성 작업 표시 (유일한 유채색) |
| `accentText` | `#ffffff` | 선택 배경 위 텍스트 |
| `warning` | `#c9a227` | 경고 (아이콘·텍스트에만) |
| `danger` | `#c0392b` | 파괴적 동작 (삭제, 종료 확인) |

밝은 테마 "Paper"는 같은 토큰을 `bg #f2f2f2 / surface #ffffff / border #c8c8c8 / text #1a1a1a` 로 뒤집는다.
두 테마 모두 WCAG AA 대비(텍스트 4.5:1 이상)를 만족해야 한다.

## 4. 타이포그래피

| 역할 | 글꼴 | 크기 |
|---|---|---|
| UI 기본 | Inter (없으면 DejaVu Sans), CJK 폴백 Noto Sans CJK KR | 12px |
| UI 작은 글씨 | 같은 글꼴 | 11px |
| 제목 | 같은 글꼴, Medium | 13px |
| 고정폭 | DejaVu Sans Mono | 12px |

안티에일리어싱은 서브픽셀 없이 그레이스케일, 힌팅 slight. 글꼴 크기는 설정에서 전역 배율(100/125/150%)로만 바꾼다.

## 5. 컴포넌트 규칙

**패널(작업 표시줄)** — 화면 하단 28px. 왼콽: `MIN` 시작 버튼(텍스트, 굵게) · 실행 중 창 목록(최대 폭 160px, 활성 창은 하단 2px accent 선). 오른콽: 트레이 · 시계(`HH:mm`, 클릭 시 날짜) · 전원 버튼. 패널 상단 1px `border`.

**실행 메뉴** — 패널 위에 떠오르는 320×400 상자. 상단 검색 입력란(자동 포커스), 아래 결과 목록(아이콘 16px + 이름 + 회색 설명). 키 입력 즉시 필터, Enter 실행, Esc 닫기. 하단에 `터미널`, `설정`, `종료…` 고정 항목.

**메뉴** — 1px 테두리, 행 20px, 단축키는 우측 정렬 `textMuted`. 구분선 1px `border`.

**버튼** — 22px 높이, 1px `borderStrong` 테두리, 평면. 호버 시 `surfaceRaised`, 눌림 시 `accent` 테두리, 기본 버튼은 테두리 2px accent.

**창 장식(labwc 테마)** — 제목 표시줄 22px `surface`, 활성 창 테두리 1px `borderStrong`, 비활성 `border`. 제목 왼쪽 정렬 12px. 버튼은 텍스트 기호 아님: 16px 단색 아이콘(최소화 `_`, 최대화 `□`, 닫기 `×`를 1px 선으로 그린 SVG).

**포커스 표시** — 1px `accent` 테두리를 컨트롤 바깥에 추가(안쪽 내용이 움직이지 않도록).

## 6. 상호작용

| 동작 | 단축키 |
|---|---|
| 실행 메뉴 | `Super` 또는 `Super+Space` |
| 터미널 | `Super+Enter` |
| 창 전환 | `Alt+Tab` / `Alt+Shift+Tab` |
| 창 닫기 | `Alt+F4` |
| 최대화 토글 | `Super+Up` |
| 좌/우 반쪽 타일 | `Super+Left` / `Super+Right` |
| 파일 관리자 | `Super+E` |
| 설정 | `Super+I` |
| 잠금 | `Super+L` (M2) |

마우스: 더블클릭 제목 표시줄 = 최대화 토글, 휠 패널 = 창 순환. 드래그·드롭은 파일 관리자에서만.

## 7. 아이콘·로고

- 아이콘은 1px 또는 1.5px 선으로 그린 단색 SVG, 16/24px 그리드에 정렬. 색은 `text` 토큰을 상속.
- 로고: 정사각형 안의 `MIN` 세 글자(고정폭, 대문자). 색은 `text`/`bg` 두 가지만.
- 서드파티 앱 아이콘은 freedesktop 아이콘 테마(기본 `Adwaita` 심볼릭 → 추후 `MIN Icons`)로 표시.
