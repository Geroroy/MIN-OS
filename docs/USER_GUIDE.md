# 하그라 사용자 안내 (HAGRA User Guide)

> 대상: 하그라 0.1.0 RC. 영어 UI 는 로그인 언어가 한국어가 아닐 때 자동으로 쓰인다 (설정 → 언어와 지역).

## 1. 화면 구성

| 영역 | 설명 |
|---|---|
| **작업 표시줄** (아래, 52px) | 왼쪽 **하그라** 버튼 = 실행 메뉴. 가운데 열린 창 목록. 오른쪽 표시기(네트워크·소리·배터리·알림) · 시계 · 전원. 위치는 설정 → 모양과 테마 → 패널에서 위/아래. |
| **실행 메뉴** (Super+Space) | 검색창 · **앱 / 즐겨찾기 / 시스템** 탭 · 바닥의 **설정**·**전원** 버튼. 검색은 이름·영문 이름·설명·초성(ㅌㅁ → 터미널)을 찾는다. |
| **바탕 화면 우클릭** | 응용 프로그램 · 터미널 · **개인 설정 ▸ 배경 바꾸기 / 모양과 테마 / 디스플레이 설정** · 설정 · 전원 |
| **보그라** 웹 브라우저 (Super+B) | 보그라(Bogra, 명령 `hagra-browser`). 실행 메뉴 즐겨찾기·바탕 화면 우클릭에도 있다. 자세한 내용은 §5.1 |
| **설정** (Super+I) | 모양과 테마 · 배경 · 디스플레이 · 소리 · 키보드와 마우스 · 언어와 지역 · 네트워크 · 알림 · 전원 · 접근성 · 정보 |

## 2. 테마 바꾸기 (세 가지 길)

1. 실행 메뉴 → **설정** 버튼 → 모양과 테마.
2. 실행 메뉴 → **시스템** 탭 → **모양과 테마**.
3. 바탕 화면 우클릭 → **개인 설정 ▸ 모양과 테마**.

테마 카드를 클릭(또는 방향키 + Space)하면 바로 저장·적용된다. **밝게/어둡게** 로 같은 계열의 밝은·어두운 테마로 바꾸고, **포인트 색** 은 테마가 검증한 변형 중에서 고른다. **기본 테마로** 가 되돌린다.
제공 테마: 연한 단청(기본, 밝음) · 깊은 단청(밝은 본문 + 짙은 패널) · 밤 단청(어두움).
배경은 설정 → 배경에서 격자 중 하나를 고르거나 경로를 직접 넣는다. 테마를 바꿔도 직접 고른 배경은 유지된다.

## 3. 창 다루기

| 동작 | 방법 |
|---|---|
| 창 전환 | Alt+Tab / Alt+Shift+Tab, 작업 표시줄 항목 클릭 (활성 창 클릭 = 최소화) |
| 창 메뉴 | 작업 표시줄 항목 우클릭 → 활성화/최소화 · 최대화 · 닫기. 제목줄 우클릭 → labwc 창 메뉴 |
| 닫기 | Alt+F4 또는 Super+Q, 작업 표시줄 항목 가운데 클릭 또는 × |
| 최대화 / 최소화 / 전체 화면 | Super+↑ / Super+↓ / Super+F, 제목줄 두 번 클릭 |
| 반 화면 붙이기 | Super+← / →, Super+Shift+↑ / ↓, 또는 창을 화면 가장자리로 끌기 (위쪽 = 최대화). Alt+방향키는 앱에 넘긴다 (브라우저 뒤로/앞으로) |
| 작업 공간 (4개) | Super+1~4 이동, Super+Shift+1~4 창 보내기, Super+Ctrl+←/→ 이웃 작업 공간 |
| 터미널 | Super+Enter |
| 알림 센터 | Super+N 또는 작업 표시줄 종 아이콘. 방해 금지는 센터 위쪽 체크 |
| 달력 | 시계 클릭 |
| 전원 | Super+Esc 또는 작업 표시줄 전원 버튼: 시스템 종료 · 다시 시작 · 로그아웃 |

## 4. 키보드만으로

모든 하그라 UI 는 Tab/Shift+Tab 으로 이동하고 Space/Enter 로 실행, Esc 로 닫는다. 포커스 링(2px)이 항상 보인다. 실행 메뉴에서는 ↑/↓ 로 항목, Ctrl+Tab 또는 Ctrl+←/→ 로 탭, F2 로 즐겨찾기 추가/제거.
설정 → 접근성에서 글자 크기(100~160%)와 굵은 포커스 표시를 켤 수 있다.

## 5. 한글 입력

fcitx5 + fcitx5-hangul 이 설치된 이미지에서는 세션 시작 때 입력기가 자동으로 뜬다. 한/영 전환은 Shift+Space(fcitx5 기본) 또는 한/영 키. 상태는 설정 → 언어와 지역 → 한글 입력기에서 확인하고 다시 시작할 수 있다. 키보드 배치(kr/us)와 배치 전환 키는 설정 → 키보드와 마우스.

## 5.1 웹 브라우저 — 보그라

보그라는 Qt WebEngine(Chromium 엔진) 위에 하그라 UI 를 입힌 기본 브라우저다. 링크·`xdg-open`·`$BROWSER` 로 여는 웹 주소도 이 브라우저로 열린다.

| 동작 | 방법 |
|---|---|
| 주소·검색 | 주소 표시줄(Ctrl+L)에 주소 또는 검색어. 주소처럼 보이면 열고(`naver.com` → https), 아니면 검색 엔진으로 검색 |
| 탭 | 새 탭 Ctrl+T · 닫기 Ctrl+W(또는 탭 가운데 클릭) · 다음/이전 Ctrl+Tab / Ctrl+Shift+Tab · 닫은 탭 다시 열기 Ctrl+Shift+T. 링크의 새 창·팝업도 탭으로 열린다 |
| 이동 | 뒤로 Alt+← · 앞으로 Alt+→ · 새로 고침 F5 (캐시 무시 Ctrl+Shift+R) · 시작 페이지 Alt+Home |
| 찾기·확대 | 페이지에서 찾기 Ctrl+F (다음 F3, 이전 Shift+F3) · 확대 Ctrl++ · 축소 Ctrl+- · 원래 크기 Ctrl+0 · 전체 화면 F11 |
| 자주 가는 곳 | 주소 표시줄의 ★(Ctrl+D)로 추가/빼기. 새 탭의 시작 페이지에 바로 가기로 보인다 |
| 검색 엔진 | ☰ 메뉴 → 검색: 구글(기본) · 네이버 · 다음 · 덕덕고 · 빙 |
| 내려받기 | `~/Downloads`(또는 XDG 다운로드 폴더)에 저장. 아래쪽 막대에서 진행·취소·폴더 보기 |
| 권한 | 위치·카메라·마이크·화면 공유·알림은 사이트마다 위쪽 막대에서 허용/차단을 묻는다. 허용한 사이트 알림은 하그라 알림 센터로 온다 |
| 오른쪽 클릭 | 링크 새 탭에서 열기·주소 복사·저장, 이미지 복사·저장, 잘라내기/복사/붙여넣기, 선택한 글 검색, 페이지 소스 보기 |

브라우저 데이터: 쿠키·저장소 `~/.local/share/hagra/browser/`, 캐시 `~/.cache/hagra/browser/` (☰ → 캐시 비우기), 설정(검색 엔진·자주 가는 곳) `~/.config/hagra/browser.conf`.

## 6. 설정이 저장되는 곳

| 설정 | 파일 (`~/.config/hagra/`) | 적용 시점 |
|---|---|---|
| 테마·포인트 색·배경 | `theme.conf` | 즉시 |
| 글자 크기·포커스 강조 | `accessibility.conf` | 즉시 (하그라 앱) |
| 패널 위치·초 표시 | `panel.conf` | 즉시 |
| 알림(방해 금지·시간·위치) | `notifications.conf` | 즉시 |
| 즐겨찾기 | `launcher.conf` | 즉시 |
| 브라우저 검색 엔진·자주 가는 곳 | `browser.conf` | 즉시 |
| 디스플레이(해상도·배율) | `display.conf` | 즉시 + 로그인 때 복원 |
| 키보드·마우스 | `input.conf` | 포인터·반복 즉시, 배치는 재구성/다음 로그인 |
| 언어·시간 형식 | `locale.conf` | 다음 로그인 |
| 커서 테마·크기 | `cursor.conf` | 다음 로그인 |

라이브 ISO 에서는 홈 디렉터리가 휘발성이라 재부팅 후 남지 않는다 (설치된 시스템에서는 유지).

## 7. 문제가 생기면

- 셸이 사라지면 세션이 자동으로 다시 띄운다 (1분에 5회 초과 시 중단; `~/.local/state/hagra/shell-crashes.log`). 직접: 터미널에서 `hagra-shell`.
- 로그: 설정 → 정보 → 진단(세션 로그 `~/.local/state/hagra/session.log`, 셸 로그 `$XDG_RUNTIME_DIR/hagra-shell.log`).
- 테마가 깨지면 `hagra-theme reset` 또는 설정 → 모양과 테마 → 기본 테마로.
- labwc 설정 되돌리기: `~/.config/hagra/labwc/` 의 재정의 파일을 지우고 Super+Shift+R.
