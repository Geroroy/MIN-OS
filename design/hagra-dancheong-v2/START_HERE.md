# 하그라 선택형 테마 전달 자료

Claude Code에 이 폴더 전체와 아래 지시를 전달하세요.

> CLAUDE_TASK.md를 읽고 ‘깊은 단청’을 설정 → 모양 → 테마의 추가 선택지로 구현해. 기존 연한 단청과 다른 테마, 기본 선택값, 사용자 설정을 보존하고 자동으로 교체하지 마. 테마 전환·선택 저장·재부팅 후 복원·기존 테마로 복귀까지 구현하고 검증해.

이 패키지의 색·문양·QML·labwc 프리셋은 깊은 단청 테마 전용입니다. 전역 테마 파일을 그대로 덮어쓰는 설치 패키지가 아닙니다. tokens.json 및 theme-manifest.json을 기존 테마 관리자에 통합하세요. 실제 OS 변경 및 Claude 실행은 아직 수행하지 않았습니다.
