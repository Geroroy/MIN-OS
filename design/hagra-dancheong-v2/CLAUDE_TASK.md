# Claude Code 실행 지시 — 하그라 선택형 테마: 깊은 단청

Geroroy/MIN-OS의 최신 작업 상태에서 이 패키지를 적용하라. 계획으로 끝내지 말고 구현·검증·변경 요약까지 수행하라. 사용자 미커밋 변경과 AGENTS.md를 먼저 확인하고 기존 작업을 보존하라. 특정 과거 커밋으로 되돌리지 마라.

## 최우선 요구: 기존 테마를 보존하고 선택지로 추가

기존 ‘연한 단청’을 포함한 모든 기존 테마·자산·사용자 설정·기본 선택값을 보존한다. 이번 디자인은 독립 테마 ID `hagra-dancheong-deep`, 표시 이름 ‘깊은 단청’으로 추가한다. 설치나 업데이트만으로 자동 활성화하지 마라. 아래 팔레트는 이 테마가 선택된 경우에만 적용한다. reference/dancheong-cranes.jpg와 dancheong-eaves.jpg의 짙은 목부 녹색, 녹청, 주홍, 군청, 황토, 적갈색, 분백 계열을 사용한다. tokens.json의 HEX는 사진의 조명 영향을 그대로 복사한 값이 아니라 UI용으로 조정한 설계값이다. 미니멀리즘 제한은 없다. 전통 단청의 구조적 겹테두리·연화·구름·휘를 현대적인 실제 운영체제 부품으로 재구성한다. 무지개 띠만 붙이고 완료하지 마라.

기존 OS 이름 하그라, Linux 기반 Qt6/QML+C++/Wayland/labwc 구조, M0/M1 검증 이력, ARM64/Android/Termux 경로와 CI는 보존한다. 내부 패키지·세션·D-Bus 이름을 일괄 변경하지 마라. 로그인 소리는 기존 사용자 결정인 풍경 소리를 유지한다. 음원 교체는 이번 범위가 아니다.

## 읽을 순서와 기준

CLAUDE_TASK.md → docs/CHANGE_V2.md → tokens.json → qml/Theme.qml → docs/INTEGRATION.md → reference의 두 사진 및 새 콘셉트 이미지가 있으면 해당 이미지 순서로 읽어라. 콘셉트는 방향 기준이고 HEX·상태별 가독성은 토큰과 문서가 우선한다. SVG 자산은 실제 적용 가능한 초안이며 생성 시안의 모든 세부를 구현했다는 뜻이 아니다.

저장소의 README.md, DEVELOPMENT_PLAN.md, docs/ARCHITECTURE.md, docs/DESIGN_LANGUAGE.md, libs/minui/, shell/, session/labwc/, files/, tests/shell/, android/의 실제 현황을 조사하라. 패키지의 API가 최신 저장소와 다르면 기존 공개 API를 보존하여 어댑트하라.

## 구현할 시각적 역할

- 바탕 bg #183C35. 문양은 중앙 작업 영역보다 화면 가장자리와 큰 모서리에 집중한다. 밝은 녹청 #2FA58F 구름, 주홍 #C74729 연꽃, 군청 #203C7A 겹선, 황토 #C29A4B 세부를 사용한다. 검은색 바탕이나 네온으로 바꾸지 마라.
- 활성 제목 표시줄 titleActive #28574A + titleText #F2EADB. 비활성 titleInactive #52695A + titleInactiveText #F2EADB. 제목 아래 18px 연화 문양 띠, 6px 내부 장식 프레임, 24px 모서리 초안을 기준으로 조정한다. 활성은 경계 두께/제목 강조도 함께 사용한다.
- 파일 목록·본문·입력칸 surface #F2EADB + text #20352E. 긴 글을 읽는 본문에 문양이나 나뭇결을 깔지 마라. 다크 모드 전체 전환은 이번 요구가 아니다.
- 패널 panel #183C35 + panelText #F2EADB. 사이드바 sidebar #28574A + sidebarText #F2EADB. 흰 글씨를 밝은 선택 영역에 남기지 말고 selection #BDD7C6 + selectionText #20352E로 전환한다.
- 일반 기본 버튼 accent #28574A + accentText #F2EADB. 주홍 coral은 장식색이고 오류는 danger #A52E20 및 아이콘/문구로 구분한다. 주홍 바탕의 조작 부품에는 일반 text 토큰을 무조건 사용하지 마라. 밝은 전경을 사용하고 대비를 검사하라.
- 키보드 focus는 밝은 본문에서 군청 #203C7A 외곽선, 어두운 패널에서 밝은 분백 외곽선을 사용한다. 폴더 아이콘은 공통 실루엣과 종류 표시를 유지하며 24/32/48/72px 가독성을 확인한다.

## 실제 수정 순서

1. design/hagra-dancheong-v2/에 패키지를 편입한다. 기존 v1의 실행 리소스와 테마를 유지한다. 깊은 단청의 토큰·배경·아이콘·문양·labwc 프리셋은 독립 경로에 추가하고, 사용자가 선택한 테마에 따라 리소스를 해석한다. 전역 Theme.qml을 이 패키지의 정적 Theme.qml로 덮어쓰지 마라. 제공 QML은 깊은 단청 전용 토큰 스냅샷이며 기존 Theme 공개 API 뒤에서 선택형으로 연결한다. 토큰 이름은 호환 유지하고 새 전경 토큰을 추가한다. QML 리소스/qrc/CMake 설치 경로까지 연결한다.
2. 테마 관리자와 설정 저장 방식을 먼저 조사한다. 기존 기능이 있으면 확장하고 없으면 최소한의 테마 레지스트리·선택 상태 저장·안전한 기본값 복귀를 구현한다. Theme.qml 및 하드코딩 색상을 조사한다. 제목/패널/사이드바의 Text·아이콘 tint를 각 전용 전경 토큰으로 바꾼다. 색상만 일괄 치환하지 마라. 버튼, 입력, 메뉴, 툴팁, 체크박스, disabled, hover, pressed, focus, selection, error를 확인한다.
3. 기존 SVG 초안을 재사용하고, 생성 시안과 차이가 큰 문양은 SVG 원본을 다듬는다. 검은 윤곽 대신 짙은 녹색/군청 중심으로 겹테두리를 구현한다. UI 콘텐츠를 스크린샷으로 덮지 마라. 원본 사진은 색상·문양 참고용이며 제품 배경으로 그대로 배포하지 마라.
4. 활성/비활성 labwc 장식은 설치된 버전이 지원하는 키만 쓴다. 전역 SSD의 제약을 확인하고 구현 가능한 색·경계·버튼부터 적용한다. 문양 프레임의 앱 내부 CSD/오버레이와 전역 SSD 범위를 혼동하지 마라. 전역 프레임이 안 되면 앱 내부 장식으로 구현하고 실제 차이를 기록한다.
5. 하단 패널 52 논리 px를 적용할 때 popup 위치·exclusive zone·최대화 작업 영역을 함께 맞춘다. 좌측 실행 도구막대는 실제 실행 및 키보드 동작이 가능한 경우만 셸에 추가한다. 고정 시계·가짜 알림·미동작 버튼을 실제 기능처럼 넣지 마라.
6. 파일 관리자가 미완성이면 독립 디자인 갤러리로 검증하고 예제 상태를 문서화한다. 실제 파일 삭제/마운트 등 새 기능을 무리하게 추가하지 마라. 한국어 경로·IME·혼합 파일명·긴 이름이 잘리지 않도록 한다.
7. 배경 SVG는 정적 PNG로 렌더링해 사용한다. ARM64 소프트웨어 렌더링을 고려하여 실시간 블러/무한 문양 애니메이션을 추가하지 마라. 테마 선택이나 접근성 모드가 기존에 있으면 보존한다.
8. 저장소의 기존 빌드와 make shell, make test-shell을 실행한다. 변경에 해당하는 테스트만 보완한다. 기존 검사 이름이 달라졌으면 현행 명령을 사용하고 기록한다. boot/image/session 변경이 있으면 QEMU 회귀를 수행한다.
9. 실제 UI를 1280×720/1920×1080, 100/150/200% 배율에서 확인한다. Tab/Enter/Space, 포인터, 포커스, 한글 조합, 이미지 누락, 활성/비활성 구분, 대비를 검사한다. 시안/실제 화면의 차이를 수정하고 스크린샷을 남긴다.

## 테마 선택 동작과 추가 완료 조건

- 설정 → 모양 → 테마에 기존 테마와 ‘깊은 단청’을 함께 보여준다. 각 테마 이름·미리보기·현재 선택 표시를 제공한다.
- 기존 기본 테마와 사용자 선택을 그대로 유지한다. 깊은 단청은 사용자가 선택했을 때만 활성화한다. v1이 실제로 미통합 상태라면 완료된 기존 테마라고 허위 표시하지 말고 현재 구현 상태를 기록하며 보존한다.
- 선택 시 셸·앱·본문·제목·패널·아이콘·장식·배경의 테마 자산을 일관되게 전환한다. 사용자가 별도 지정한 배경은 유지하며 ‘테마 기본 배경 사용’을 별도로 선택할 수 있게 한다.
- 선택한 테마 ID를 기존 설정 저장소에 저장하고 재로그인·재부팅 후 복원한다. 기존 설정 키가 있으면 재사용하고 임의로 덮어쓰지 마라.
- 알 수 없는 ID나 자산 누락 시 기존 기본 테마로 복귀한다. 사용자 개인 labwc 설정 전체를 덮지 말고 관리되는 테마 부분만 선택적으로 전환한다.
- 런타임 변경이 가능한 부분은 즉시 적용한다. labwc 장식처럼 재로딩이 필요한 부분은 지원되는 절차를 확인해 적용한다. 세션 재시작이 꼭 필요하면 변경 전에 안내하며 강제 로그아웃하지 마라.
- 테마 변경으로 로그인 풍경 소리, 키보드·접근성 설정, 패널 배치 같은 무관한 사용자 설정을 초기화하지 마라.
- 기존 테마 → 깊은 단청 → 기존 테마 왕복, 선택 저장/복원, 잘못된 ID 복귀를 실제로 검증한다. 기존 테마의 시각과 기능이 회귀하지 않는지 전후 화면으로 확인한다.

## 완료 보고

변경 파일, 실제 구현 화면, 실행한 검증과 결과, 환경 때문에 실행 못 한 항목, 남은 시안 차이를 보고하라. 제공 패키지 검사 통과를 OS 실행 검증으로 표현하지 마라. 실제 수행하지 않은 Android 실기기 테스트를 완료로 표시하지 마라. 사용자 요청이나 기존 명시 승인 없이 원격 푸시/병합/배포를 하지 마라.
