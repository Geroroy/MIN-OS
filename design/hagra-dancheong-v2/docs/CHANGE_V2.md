## 통합 방식 수정

기존 디자인을 대체하지 않는다. 추가 테마 ‘깊은 단청’으로 등록하고 기존 기본값을 유지한다. 아래 표는 깊은 단청 전용이다.

# 하그라 깊은 단청 v2

색상 참조: 첨부된 학 단청과 처마 단청 두 사진. 기존 창 구성·기능·기술 기반 및 파스텔 테마는 유지한다. 짙은 전통 안료 계열은 추가 선택형 테마로 제공한다. 본문은 분백색을 유지한다. HEX는 사진에서 정확히 측색한 값이 아니라 화면 가독성을 위해 조정한 설계색이다.

| 역할 | 배경 | 전경 |
|---|---|---|
| 데스크톱·하단 패널 | #183C35 | #F2EADB |
| 활성 제목·사이드바 | #28574A | #F2EADB |
| 비활성 제목 | #52695A | #F2EADB |
| 본문 | #F2EADB | #20352E |
| 보조 본문 | #F2EADB | #4D6055 |
| 선택 | #BDD7C6 | #20352E |
| 기본 버튼 | #28574A | #F2EADB |
| 오류 | #F2EADB | #A52E20 |

장식색: 녹청 #2FA58F, 주홍 #C74729, 군청 #203C7A, 황토 #C29A4B, 적갈 #643C32. 장식색을 임의의 작은 글자색으로 쓰지 않는다. 문양은 제목 아래 띠·모서리·창틀·화면 가장자리로 연결한다. 작업 본문은 평탄하게 유지한다.

assets SVG는 v1 기하를 재사용하여 색을 수정한 실행용 초안이다. 시안의 학이나 복잡한 처마를 모두 재현한 완성품이 아니다. 기존 장식 기하를 유지하면서 실제 이미지에 가까워지도록 수정할 책임은 구현 작업에 포함된다. 배경 PNG는 SVG를 사전 렌더링한 것이다. 새 이미지 생성 시안은 UI 설계 참고이며 운영체제 실행 화면이 아니다.

깊은 단청을 선택한 경우에만 이 문서의 색상 역할을 적용한다. 연한 단청을 선택하면 기존 밝은 제목 표시줄과 기존 자산을 그대로 사용한다. 풍경 로그인 소리는 유지한다.
