# 하그라 연한 단청 — 디자인 명세 1.0

## 조형 강령

현대의 작업 도구에 한국 전통의 패턴과 공예적 구조를 통합한다. 문양은 이 제품의 중심 표현이다. 풍부한 테두리와 명료한 조작이 공존해야 한다. 배경만 한국적으로 바꾸는 구현은 목표에 미달한다.

연꽃·구름·창살·보자기·매듭은 기능마다 역할을 정해 반복한다. 서로 다른 문양을 모든 표면에 동시에 채우지 않는다. 본문은 장식이 놓이는 공간과 분리하여 정확하게 읽히게 한다. 이는 미니멀리즘 요구가 아니라 작업용 OS의 가독성 요구다.

## 색상

원본은 ../tokens.json. 아래 코드는 스크린샷에서 자동 추출한 수치가 아니라 구현을 위해 정규화한 설계 값이다.

| 활성 제목 | #D2E2D5 | 청자빛 회백색 |

| 본문 글자 | #203F42 | 제목·본문·주요 기호 |
| 보조 글자 | #536963 | 경로·상태·설명 |
| 포커스 | #28717B | 2px 경계 |

연한 색 위에는 흰 글자를 기본으로 쓰지 않는다. 산호색 닫기 버튼도 짙은 ×를 사용한다. 실제 accent 버튼은 #28717B 위에 #FFFFFF. 읽을 수 있는 상태 정보에는 장식 색보다 의미별 토큰을 사용한다.

## 치수와 글꼴

모든 치수는 100% 기준 논리 px. PNG의 물리 픽셀을 그대로 앱 좌표에 쓰지 않는다.

| 항목 | 기준 |
|---|---|
| 기본 단위 | 4 |
| 본문 글꼴 | Noto Sans CJK KR, 15px |
| 보조 글자 | 13px |
| 창 제목 | 16px, 활성 600·비활성 400 권장 |
| 일반 컨트롤 | 최소 높이 36 |
| 행 | 높이 40 |
| 창 제목줄 | 40 |
| 장식 띠 | 18 |
| 장식 프레임 | 6, 모서리 장식 24 |
| 아이콘 | 도구 24, 폴더 72 |
| 하단 패널 | 52, 장식 띠와 콘텐츠의 높이 합에 맞춤 |
| 좌측 레일 | 72 |
| 내부 여백 | 8 / 16 |
| 기본 모서리 | 2 |
| 포커스 선 | 2 |

패널은 최소 52이고 내부 실제 배치에 따라 늘릴 수 있다. 레일과 패널이 교차하는 모서리에 중복 예약 영역을 만들지 않는다. 고정 52 높이 안에 18 띠와 36 컨트롤을 겹치게 넣지 말고, 띠를 상단 8px 축소형으로 쓰거나 전체 패널을 늘린다. panelHeight는 최종 레이아웃과 항상 일치시킨다.

장식만을 위한 붓글씨 본문, 작은 픽셀 글꼴, 자간이 넓은 파일명은 사용하지 않는다. 글꼴 패키지 설치와 fallback을 확인한다. 한글 입력기는 별도 구현 과제이며 글꼴 변경으로 해결되었다고 보고하지 않는다.

## 문양 배치

| 표면 | 기본 표현 | 제약 |
|---|---|---|
| 제목 아래 | 반복 연화 띠 | 제목·버튼의 클릭 영역 침범 금지 |
| 창틀 모서리 | 소형 꽃 중심 결구 | 드래그·리사이즈 영역을 막지 않음 |
| 바탕화면 | 구름과 큰 연화·창살 | 글자와 아이콘 주변 명도 확보 |
| 사이드바 하단 | 옅은 창살, 매듭 포인트 | 목록 행 뒤에는 낮은 밀도 |
| 폴더 | 단청·보자기·연화 포인트 | 유형별 실루엣 일관성 유지 |
| 하단 패널 | 얇은 반복 띠 | 알림·전원·시계는 명료하게 |
| 메뉴와 입력칸 | 테두리 또는 한 모서리 | 입력 문자열 위 패턴 금지 |
| 오류·경고 | 의미별 기호·문구 | 꽃 모양만으로 상태 표현 금지 |

SVG는 반복 단위로 타일링한다. 9-slice 장식이 필요하면 모서리·변·중앙을 나누며 꽃잎이 가로로 늘어나지 않게 한다. 제공 band는 가로 반복용, 세로 변에는 단색 겹선과 모서리를 우선 사용한다.

## 상호작용

- 기본: 밝은 표면, 짙은 글자, 얇은 경계.
- 호버: 배경을 약간 진하게. 문양을 크게 키우거나 반복 이동하지 않음.
- 눌림: 내부 음영 또는 1 논리 px 오프셋. 레이아웃 재배치 없음.
- 선택: 연살구 배경과 선택 표시. 포커스와 별도 상태.
- 포커스: 짙은 청록 2px 경계, 장식 경계보다 앞에서 보이게 함.
- 비활성: 낮춘 대비+동작 차단. 키보드/접근성에서도 차단 확인.
- 오류: 오류 토큰, 표준 오류 기호, 해결 문구. 색만으로 전달하지 않음.
- 진행: 상태 문구와 진행 표시. 전통 문양 전체의 상시 회전 효과 금지.

닫기 ×, 최소화 −, 최대화 □는 표준 의미를 유지한다. 장식은 주변 프레임에 둔다. 아이콘만 있는 버튼은 툴팁·접근성 이름을 제공한다.

## 화면 배치와 배율

1280×720/100%에서 대표 화면을 먼저 구현하고 1920×1080에서 비교한다. 기준 PNG는 1672×941로 확인하며 임의 해상도에 맞춰 구성 요소별로 재배치한다. 150%·200% 배율은 가용 논리 공간이 줄어드는 조건으로 검증한다.

폭이 부족하면 파일 그리드 열 수를 줄이고 레일은 숨김/접기, 사이드바는 접기, 메뉴는 오버플로로 옮긴다. 문구 크기를 줄여 모든 요소를 억지로 집어넣지 않는다. 높이가 부족하면 본문만 스크롤하며 창 버튼과 주요 탐색은 유지한다. 터치 프로필은 44 논리 px 이상의 주요 타깃을 별도로 검증한다.

## 성능·접근성

장식은 정적 SVG 또는 사전 렌더링 PNG를 사용한다. 모듈 설치에 Qt SVG 지원을 포함하고 누락 시 안전한 단색 프레임으로 fallback한다. 배경은 사전 렌더링하여 고정 텍스처로 표시한다. 새로운 고비용 실시간 blur/shader 의존성을 추가하지 않는다.

고대비·큰 글자·동작 줄이기를 고려하고 장식 숨김 선택지를 제공할 수 있게 구조화한다. 이것이 기본 단청 테마를 축소하는 이유가 되어서는 안 된다. 장식은 접근성 트리에 읽힐 텍스트로 노출하지 않는다.
