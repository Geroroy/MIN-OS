# 하그라 · 연한 단청 디자인 전달 패키지 1.0

Claude Code에 이 폴더 전체를 전달하고 `CLAUDE_TASK.md`를 읽고 실행하도록 지시하세요.

## 기준과 우선순위

1. 이 패키지의 강령과 사용성 요구사항
2. `tokens.json`의 수치와 의미
3. `docs/DESIGN_SPEC.md`의 구조·상태 규칙
4. `reference/hagra-dancheong-concept.png`의 시각적 인상

이미지는 생성형 콘셉트입니다. 구현을 증명하는 스크린샷이 아닙니다. 이미지의 문구, 파일 수, 날짜, 기능은 검증된 제품 명세로 간주하지 않습니다.

## 확정된 방향

- 이름: **하그라**. HAGRA는 임시 영문 식별 표기.
- 현대적인 조작과 한국 전통 조형을 결합한 독창적인 국산 Linux 기반 OS.
- 미니멀리즘 제약 해제. 단청·연화·구름·창살·보자기·매듭을 적절한 밀도로 적극 도입.
- 색은 연한 청자·산호·청회·살구·백자 계열. 제목 표시줄은 밝은 청자빛 회백색.
- 뮷즈는 참고 사례 중 하나이며, 특정 브랜드나 상품에 디자인을 한정하지 않음.
- NeXTSTEP은 창의 명확한 구조와 도구성에 참고. 특정 OS의 외형 복제를 목표로 하지 않음.
- 화면의 테두리와 도구에 풍부한 문양을 사용하고 텍스트·입력·파일명은 읽을 수 있게 설계.

## 적용 상태

이 패키지는 **디자인 명세와 구현용 초안**입니다. 저장소의 기본 브랜치를 수정하거나 PR을 생성하지 않았습니다. 전체 데스크톱 스킨, 상호작용, QML 실행, labwc 전역 장식 적용은 Claude가 대상 환경에서 구현·검증해야 합니다.

Qt 실행 도구가 설치된 환경에서는 `qml qml/Gallery.qml` 또는 배포판의 Qt 6 QML 실행기로 미리볼 수 있습니다. 파일명·실행기 경로는 배포판마다 확인하세요. 이 갤러리의 일반 컨트롤은 Qt 기본 스타일이며 완성된 MinUI 스킨이 아닙니다.

## 자산 출처

기준 이미지는 이 대화에서 AI로 생성한 콘셉트입니다. SVG와 코드 초안은 이 전달 패키지를 위해 새로 작성했습니다. 전통 문양에서 영감을 받은 현대적 해석이며 특정 문화유산의 정확한 복원·공식 인증을 주장하지 않습니다. 외부 유료 자산, 뮷즈 상표·로고·상품 도안을 포함하지 않습니다. 저장소에 편입할 때 기존 라이선스 정책에 맞춰 출처와 생성 이력을 기록하세요.
